Ticket triage — one call, three measurements

Routing and triage are usually done with a full chat completion that hands back a word. EasyAI.decide() hands back numbers, and asks all three questions in a single small call. The thresholds below are plain Java constants in TriageBean — the model measures, your code decides.

Needs easyai.decision.api-key pointed at OpenAI (see the comment in this page's source). Groq and DeepSeek do not implement the decisions endpoint.
