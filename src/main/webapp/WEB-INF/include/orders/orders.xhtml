Vision demo — app-server setup (read before trying)

Attach an invoice image in the AI panel and ask "compare this invoice with the open order". Two prerequisites:

1. Set DEEPSEEK_API_KEY — env var, JVM -D, or a line in easyai.properties (DEEPSEEK_API_KEY=sk-...). Never commit it.

2. Make sure the app-server truststore has the public CA roots (GlassFish ships only internal ones), so DeepSeek's HTTPS cert validates. One-time bulk import — no per-certificate splitting needed, because the TLS store is opened in code (services.DeepSeekVision):

keytool -importkeystore -srckeystore "%JAVA_HOME%\lib\security\cacerts" -srcstorepass changeit -srcstoretype PKCS12 -destkeystore "<server>\domains\domain1\config\cacerts.p12" -deststorepass changeit -deststoretype PKCS12 -noprompt

Find the active truststore via System.getProperty("javax.net.ssl.trustStore"); back it up first and restart the domain after. (The Groq tab needed a manual per-host cert import — this does not.)

Voice demo — how to try it

The microphone is push-to-talk by clicking twice, not by holding. Open the AI panel (the sparkle button, top right), then:

1. Click 🎤 and allow the microphone when the browser asks. The button turns red and pulses while it is recording.
2. Say your question — for example "what is the status of order ORD-004?".
3. Click 🎤 again to stop. That is what sends the recording.

You then see your own words as the "you said …" bubble and the answer below it — the same tab-aware assistant that answers typed questions, so it can use the tools of this tab. The answer is also spoken back.

🔊 next to the microphone mutes and unmutes the spoken answers, and cuts off the sentence in progress. Clicking 🎤 while it is talking also stops it — you always win.

Two notes. The page must be opened over https:// or http://localhost… — browsers only give microphone access in a secure context. And speaking is "armed": the assistant speaks only after you have spoken at least once, so typed turns stay silent. Once armed, a proactive suggestion is read aloud too.

Transcription runs on Groq (easyai.api-key, easyai.stt.model-name=whisper-large-v3); the spoken answer uses OpenAI (easyai.tts.api-key). Without the OpenAI key nothing breaks — it falls back to the browser's own voice.
